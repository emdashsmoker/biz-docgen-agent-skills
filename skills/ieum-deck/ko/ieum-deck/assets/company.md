# 회사 프로필 (사용자 작성)

- company.md 는 제안사 정보를 한곳에서 관리하는 입력 양식
- 표의 값은 사용자가 제공한 자료로만 채움
- 확인하지 못한 값은 `[회사 확인]` 으로 남김
- 남은 `[회사 확인]` 은 완료 보고에 확인 요청으로 기재
- 변환 스크립트는 제목의 첫 낱말(기본, 연혁, 조직, 재무, 실적)과 "헤드라인", "관리 방법론" 제목으로 내용을 찾음
- 제목은 수정하지 않음
- 표의 행 수는 회사 규모에 맞게 조정
- 이 양식을 작업 폴더에 복사하여 작성 (스킬 폴더의 양식은 그대로 유지)
- 작성 후 `python3 scripts/company2slides.py <작업 폴더>/company.md <작업 폴더>/common-slides.json` 으로 공통 파트를 생성

## 헤드라인

- 괄호 안 키의 문구는 해당 제안업체 현황 슬라이드의 헤드라인으로 쓰임
- 문구가 비어 있으면 표 값으로 헤드라인을 작성 (일반 현황은 설립연도와 사업 분야, 조직은 본부와 팀 수와 임직원 수, 경영 상태는 매출액 증감, 수행 실적은 실적 건수)
- 괄호 안의 키는 수정하지 않음
- (일반 현황)
- (조직)
- (경영 상태)
- (수행 실적)

## 관리 방법론

- 각 문구는 해당 관리 슬라이드의 헤드라인으로 쓰임
- 문구는 회사 방침에 맞게 수정
- 괄호 안의 키는 수정하지 않음
- (진도) 주 단위 실적 집계로 계획 대비 편차 구간별 대응 기준 적용
- (품질) 산출물별 품질 기준에 따른 주 단위 점검으로 품질 수준 관리
- (보고) 정기 회의 및 수시 보고로 진행 상황을 발주기관과 공유
- (산출물) 단계별 제출 시점에 맞추어 산출물을 발주기관에 제출
- (보안) 물리, 기술, 관리 보안의 통제 범위 구분으로 과업 자료 보호
- (개인정보) 개인정보 처리 단계별 보호 조치로 조사 자료 보호
- (비상) 비상 상황 보고 순서의 사전 지정으로 초기 대응 시간 단축
- (사후지원) 과업 종료 후 무상 사후 지원으로 산출물의 현장 정착 지원
- (추가제안) 방법론 및 분석 도구 이전으로 발주기관의 자체 수행 역량 보완
