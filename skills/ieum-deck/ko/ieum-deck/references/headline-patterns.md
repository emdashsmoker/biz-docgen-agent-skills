# 헤드라인 문형

- 주제별 문형이 있는 슬라이드의 헤드라인은 storyline 단계에서 문형에 키워드만 치환
- storyboard 작성 단계는 확정한 헤드라인을 그대로 사용
- 문형이 없는 주제의 헤드라인은 storyline 단계에서 `references/writing-rules.md` 에 맞춘 결론 문장으로 작성

## 대상 지칭어

- 문형의 "본 과업" 은 기본값
- 기본값은 과업에 맞는 지칭어로 교체
- 1순위 기준은 RFP, 계약서, 발주기관 서식의 표기
- 1순위 표기가 있으면 그 표기를 그대로 사용
- 2순위 기준은 산출물의 성격
    + (본 연구) 조사, 분석, 검증이 주된 산출물인 과업 (실태조사, 정책연구, 지표 개발 연구)
    + (본 과업) 진단, 전략 수립, 체계 구축, 제도 개선, 워크숍 운영 등 컨설팅 성격의 과업
    + (본 과제) 공모 선정 단위를 과제로 부르는 과업
    + (본 사업) 지원사업 운영, 실증사업, 구축사업
    + (본 프로젝트) 민간 기획, 사내 기획, 프로젝트로 부르는 공공 과업
    + (본 보고서) 보고서형 PPT 와 브리핑 덱에서 문서 자체를 가리키는 경우
- 지칭어 후보가 여럿이거나 RFP 표기가 없으면 착수 질의에서 사용자에게 확인
- (확인 문구 예시) "이 문서를 본 과업, 본 연구, 본 과제, 본 사업, 본 프로젝트, 본 보고서 중 무엇으로 지칭할까요"
- 사용자가 답하지 않으면 공공 과업은 본 과업, 민간 과업은 본 프로젝트를 사용
- 기획연구와 사전기획은 본 연구나 본 과업을 사용
- 한 발표자료 안에서 지칭어는 하나로 통일 (혼용은 lint WARN)
- 지칭어를 바꾸면 뒤따르는 조사(은/는, 을/를, 과/와)도 함께 맞춤
- 지칭어는 헤드라인, 본문 라벨, 소제목에 모두 적용
    + 치환 대상은 템플릿 라벨과 견본 문구의 "과업의 목적", "과업의 배경 및 목적", "과업의 목표 및 범위", "본 과업의 최종 목표", "과업 추진 단계", "과업 종료 후"
    + 지칭어가 본 사업이면 "사업의 목적", "사업의 목표 및 범위", "사업 추진 단계", "사업 종료 후" 로 치환
    + 지칭어가 본 프로젝트이면 "프로젝트의 목적", "프로젝트 추진 단계" 로 치환
- 치환 예외는 RFP 가 정한 서식 명칭(과업지시서, 과업 세부내용 등)과 VISION, SCOPE 같은 구조 라벨
- 제안 외 산출물에 과업 라벨이 남으면 lint WARN

## 기본 문형

- (Task) Task {{N}}은 {{대상}}을 대상으로 {{방법}}을 실시하여 {{산출물}} 도출
- (분석 결과) {{대상}}은 {{발견}}
- (시사점) {{개선 대상}}의 {{개선 방향}}이 필요
- (SWOT 종합) 강점, 약점, 기회, 위협 요인을 취합하여 {{N}}개 전략 방향 도출

## 명사형 변환 규칙

- noun 문체는 존댓말 문장 전체를 명사형 문장으로 다시 씀
- 변환 후에도 조사와 서술어의 호응을 유지
    + "…을 수립하는 것을 목적으로 합니다" → "…수립을 목적으로 추진" 또는 "…수립이 목적"
    + "…을 제시합니다" → "…제시"
    + "…으로 추진됩니다" → "…으로 추진"
    + "…을 보유하고 있습니다" → "…보유"
- 변환 결과의 마지막 어절은 명사나 명사형 어미(추진, 도출, 제시, 확보, 수행)
- 변환 결과는 문장 끝에 "함" 을 붙여 읽어 호응을 확인 (예: "수립을 목적으로 추진함" 처럼 자연스럽게 읽히면 통과)
- polite 문체는 명사형 문형에 변환 규칙을 거꾸로 적용하여 존댓말 서술어로 바꿈

## 주제별 문형

- 기획과 컨설팅 슬라이드에서 반복되는 주제의 명사형 문형
- {{ }} 자리는 과업 내용으로 치환
- 나머지 어구는 과업에 맞게 다듬음
- 구성 열은 `references/templates.md` 의 템플릿 이름이나 `references/recipes.md` 의 레시피 이름
- 사업수행계획 표의 그룹 열은 주제가 속한 과업 분야 (이름은 `references/recipes.md` 레시피 목록의 그룹 이름을 사용)
- 구성 열의 레시피는 다른 그룹에 속한 레시피일 수 있음 (예: 사업기획의 시장 규모 추정에 분석 결과 그룹의 market_sizing)
