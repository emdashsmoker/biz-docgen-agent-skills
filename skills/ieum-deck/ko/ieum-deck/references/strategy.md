# 제안전략 수립

- 제안 발표자료 신규는 절차 2단계에서 아래 양식을 작성
- 제안 발표자료 변환은 원고에서 역추출한 내용을 같은 양식으로 정리

## RFP 해부 양식 (00_rfp.md)

```
## 기본조건          사업명, 발주기관, 기간, 예산(슬라이드 본문 기재 제외), 계약방법, 제출기한, 제출 서류, 발표 여부, 발표 시간
## 참가자격          업종, 지역, 인증, 실적 하한, 인력 자격 (미충족 항목은 착수 단계에서 사용자에게 보고)
## 평가표            세부평가항목 단위로 전개 (열은 평가항목, 세부항목, 평가기준 원문, 배점, 정량 여부, 대응 장)
## 과업 세부내용 (전수)   RFP 의 모든 항목을 원문 그대로 한 줄씩 이관 ([T1] [T2] 형식 ID 부여)
## 산출물과 보고      RFP 가 정한 산출물, 보고 횟수, 납품 형식
## 작성 규정          분량, 판형, 목차 지정 여부, RFP 가 제한한 표현, 참조표 의무
## 핵심 워딩
| 표준 표기 | 교체 대상 변형 | 근거 |
| 실행과제 | 이행과제, 세부과제 | RFP Ⅱ-3 |
```

- 핵심 워딩은 RFP 가 쓰는 과업명, 산출물명, 단계명, 대상 명칭 5-15개
- 핵심 워딩은 storyboard 의 `meta.rfp.wording` 에 등록
- lint 는 변형 표기의 출현을 FAIL 로 검사
- 표준 표기의 사용 여부는 심층 검토의 RFP 대응 항목에서 확인
- (대응 장) 세부평가항목의 평가 근거를 담는 발표자료의 장
- 대응 장은 장별 슬라이드 배분의 근거
- 대항목 배점은 세부항목 배점의 합계
- 슬라이드 배분의 계산 단위는 세부항목 배점
- 정량 항목(신용등급, 실적 건수)은 슬라이드 배정 대상에서 제외
- 발표 평가가 있으면 발표 시간과 질의응답 시간을 기본조건에 기재
- 분량 상한은 발표 시간에서 도출

## 제안전략 양식 (00_strategy.md)

- 항목 순서는 사고 순서
- 뒤 항목은 앞 항목에서 도출
- `[확인]` 항목은 사용자 답변, RFP 원문, 경쟁자 탐색 결과로 채움
- 경쟁자 항목의 추정 후보는 검색 출처를 함께 기재하여 사용

```
## 1 표면 목적과 이면 니즈   RFP 배경 문장의 목적. 발주기관이 실제로 얻으려는 성과(가설)와 근거. 발주 시점의 사정
## 2 최소 요건               참가자격과 실적 충족 여부. 기간과 예산 대비 과업량. 수행 불가 요소
## 3 타당성 판정             참여 여부, 사유, 보류 조건
## 4 외부 여건               발주기관을 둘러싼 정책 일정, 상위계획, 예산 심의, 유사 사업 (기회와 위협, 반영 위치)
## 5 경쟁자                  참가자격 판정, 경쟁사 유형별 예상 강약점, 경쟁 후보 기관 표, 동일 발주기관 전임 수행사, 제외 기관 (아래 경쟁자 표 양식)
## 6 자사 강점과 약점        실적, 인력, 도메인 지식, 방법론 4열. 부족한 요소와 보완 수단(컨소시엄, 자문)
## 7 제안전략                차별화 포인트 표(2-4개, 근거, 담을 타일). 추진전략 도출 표(2-4행). 스토리라인 1줄. 핵심 키워드 3개
## 8 실행 결정               연구책임자와 인력 배치. 자문위원 후보. 성공 포인트와 실패 포인트. 가격 방향(투찰 구간)
```

- 이면 니즈 가설의 후보는 상위계획 개정 주기, 감사 지적, 제도 신설 첫해, 조직 개편, 예산 심의, 전임 용역 결과의 보완 수요
- 가설은 발주기관의 산출물 활용처를 제시
- 스토리라인 1줄은 배경의 문제 인식에서 모듈과 산출물로 이어지는 문장
- 발표자료의 목차와 헤드라인 흐름은 스토리라인 문장을 따름
- 7 제안전략은 차별화 포인트 표와 추진전략 도출 표로 구성
    + 차별화 포인트 표는 "제안의 특징 및 장점" 슬라이드(features) 역량 타일의 원천
    + 추진전략 도출 표는 "추진전략" 슬라이드(strategy) 전략 기둥의 원천
- 특징 슬라이드는 제안사의 보유 자산(방법론, 실적, 인력, 도구, 데이터)을 제시
- 추진전략 슬라이드는 과업의 난점을 해소하는 수단(결과물 설계 원칙, 수행 활동의 설계)을 제시
- 같은 방법론이 두 슬라이드에 나오면 슬라이드마다 다른 내용을 배치
    + (특징 타일) 방법론의 보유 사실과 적용 실적
    + (전략 기둥) 이 과업에서의 방법론 적용 방식

### 차별화 포인트 표

| 차별화 포인트 | 근거 | 담을 타일 |
|---|---|---|
| [확인] | [확인] | [확인] |

- 포인트 수는 역량 타일 수의 범위(2-4개)에 맞춤
- 포인트마다 실적, 데이터, 인력 중 1개 이상의 근거를 붙임
- 근거 열의 실명 과업, 도구, 인력은 타일 항목의 재료
- 전략 기둥이 포인트를 근거로 쓰면 담을 타일 열에 기둥 번호를 병기

### 추진전략 도출 표

- 추진전략은 과업의 난점에서 도출 (전략 1개당 1행, 2-4행)
- 배경의 문제에서 도출한 전략은 모듈 목록의 이름만 바꾼 결과가 됨
- 도출 표는 00_strategy.md 에만 둠 (작성자의 내부 추론)
- 기둥 제목, 항목, result 는 수단과 가치의 긍정형으로 작성
    + 슬라이드의 문구는 모두 같은 무게의 독립 요소로 읽힘
    + 부정형 어구는 굵은 글씨와 테두리를 가진 result 상자에서 가장 크게 읽힘
    + 전략 슬라이드는 배경과 목적 슬라이드의 이슈(과업의 난점)에 답하는 수단만 보여도 논리가 이어짐
    + (재작성 예) 도출 표의 "현장 거부를 해소하는 수용성" 은 슬라이드에서 "부서가 수용하는 지표" 로 작성

| 과업 특성 | 위험 요인 | 추진전략 | 확보하는 가치 |
|---|---|---|---|
| [확인] | [확인] | [확인] | [확인] |

- (과업 특성) 과업이 완료해야 하는 범위와 과업이 다루는 대상의 성질
    + RFP 과업 내용, 제도 절차, 준수 의무, 제약 조건도 이 열에 기재
    + 의무는 모든 입찰자가 공유하는 전제
- (위험 요인) 과업 특성 때문에 결과물이 어긋날 수 있는 지점
- (추진전략) 위험 요인을 해소하는 특화 방안
    + 결과물 설계 원칙
    + 수행 활동의 설계 (구성 기준, 대상, 시점)
- (확보하는 가치) 위험 요인이 해소될 때 발주기관이 얻는 가치
    + 해소하는 위험 요인과 짝으로 기재
    + (기재 예) "오답 불신을 해소하는 신뢰성"
- 추진전략의 성립 조건은 특화와 차별화
    + (특화) 과업 대상의 특성에 맞춘 설계
    + (차별화) RFP 와 제도가 요구하는 수준 위에 제안사가 더하는 설계
- (의무 삭제 시험) 추진전략 열에서 RFP 과업 내용과 제도 의무의 준수를 지웠을 때 남는 방안이 전략
- 남는 방안이 없는 행은 의무의 재진술이므로 다시 작성
- 위험과 수단이 모두 범용인 행(일정 지연과 월 1회 협의회)은 수행조직이나 일정 슬라이드로 이동

### 전략 슬라이드 슬롯 대응

| 슬롯 | 채우는 내용 | 원천 |
|---|---|---|
| goal | 최종 목표 (목표와 범위 슬라이드와 같은 문구) | 00_rfp.md 기본조건 |
| strategies[].title | 전략명. 수단을 과업의 용어로 작명 (모듈명과 활동명은 제외) | 도출 표 추진전략 열 |
| strategies[].items | 수단의 구현 설계 4-5개 (대상, 구성 기준, 시점, 도구, 판정 기준) | 도출 표 추진전략 열 |
| strategies[].result | 확보하는 가치의 긍정형 (해소 위험은 기재하지 않음) | 도출 표 가치 열 |
| conclusion | 가치를 묶어 결과물을 수식하는 문장 (예: "수용성, 타당성, 착수 가능성을 갖춘 OO 체계 수립") | 도출 표 가치 열 |

- 전략명은 수단의 행위를 나타내는 동작 명사로 종결 (수립, 연계, 운영, 제시, 설계, 도출, 반영 등)
    + (산출물명 종결) "지표 체계", "로드맵" 으로 끝나는 이름은 목표와 범위 슬라이드의 산출물로 읽힘
    + (회의체명 종결) "자문위원회", "실무협의회" 로 끝나는 이름은 수행조직 슬라이드의 운영 수단으로 읽힘
    + (방법론명 종결) "로직모델", "델파이" 로 끝나는 이름은 특징 슬라이드의 보유 자산으로 읽힘
- 전략명의 재작성 예
    + "임무 연계형 지표 체계" 는 "임무와 부서 지표 정렬" 로 작성
    + "분야별 분과 위원회" 는 "기술 분야별 분과 구성" 으로 작성
    + "성과 로직모델" 은 "로직모델 적용 성과 경로 설계" 로 작성
- 기둥 항목은 기둥 폭에서 1줄로 들어가는 분량으로 작성 (16:9 기준 한글 16자 안팎)
- 2줄 항목이 있는 기둥은 다른 기둥보다 항목 간격이 좁아짐 (빌드가 남는 높이를 항목 간격으로 배분)
- 헤드라인은 `references/headline-patterns.md` 의 추진전략 문형에 기둥 제목과 같은 전략명을 치환
- 전략마다 슬라이드 1장을 배치하는 경우(정보화 관행, 배점이 큰 세부항목)는 기둥 항목을 본문으로 올림
    + 방식의 견본인 뒷받침 표(단계별 수행표, 품질 지표표, 분과 구성표, 조사 설계표)는 Sample 로 배치
    + 도출 표처럼 전략별 위험 요인이나 확보하는 가치를 정리한 표는 Sample 로 배치하지 않음
    + 견본 표의 `footnotes` 에 "참고용 시안, 확정치 아님" 을 기재

### 제시 전 자체 점검

- 위험 요인마다 답하는 기둥이 있음
- 기둥 제목과 항목에 모듈명과 활동명(진단, 조사, 자문위원회 운영)의 반복이 없음
- 기둥 제목과 헤드라인의 전략명이 동작 명사로 끝남
- 추진전략 열에서 RFP 과업 내용과 제도 의무를 지워도 수단이 남음
- 도출 표의 가치 열이 행마다 해소 위험과 짝을 이룸
- 기둥 제목, 항목, result 가 완료 시점의 선언 없는 긍정형
- 차별화 포인트마다 역량 타일이 있음
- 역량 타일의 강점은 모두 차별화 포인트 표에 있음

## 경쟁자 탐색

- 경쟁자 항목은 웹검색이 허용된 환경에서 탐색 경로(낙찰 기록, 수행 공개, 자사 유사 기관, 업종 탐색)로 채움
- 공공 용역의 수행 사실을 공개하는 기관은 소수
- 수행 공개 경로만으로는 경쟁 후보 기관 표를 채우기 어려움
- 낙찰 기록 경로와 추정 경로(자사 유사 기관, 업종 탐색)를 함께 사용
- 웹검색이 허용되지 않은 환경에서는 사용자 제공 낙찰 결과만 기재
- 웹검색이 허용되지 않은 환경의 나머지 항목은 사용자에게 질의
- 모든 경로를 수행해도 기관이 확인되지 않은 유형도 사용자에게 질의

### 참가자격 판정

- 경쟁 후보 탐색 전에 이번 공고에 입찰할 수 있는 기업 규모를 판정
- (판정 목적) 입찰 자격을 갖춘 기업으로 경쟁 후보를 구성
- 판정 근거의 1순위는 입찰공고문과 RFP 의 참가자격 문구
- 문구가 금액 기준과 달라도 문구를 따름
- 문구가 없거나 모호하면 아래 제도 기준으로 추정
- 추정한 판정 결과에는 `[확인]` 을 붙임

#### 용역 금액 기준

- 「중소기업제품 구매촉진 및 판로지원에 관한 법률 시행령」 제2조의2가 공공기관 용역의 기업 규모 제한을 정함
- (추정가격 1억원 미만) 소기업 또는 소상공인 간 제한경쟁 (중기업, 중견기업, 대기업 입찰 불가)
- (1억원 미만 완화) 입찰 가능한 소기업 또는 소상공인이 3인 이하로 명백하거나 유찰된 공고는 중소기업자 간 제한경쟁 (중기업 입찰 가능)
- (추정가격 1억원 이상 고시금액 미만) 중소기업자 간 제한경쟁 (중견기업과 대기업 입찰 불가)
- (고시금액 이상) 금액에 따른 기업 규모 제한 없음
- 중소벤처기업부장관이 지정한 중소기업자간 경쟁제품에 해당하는 용역은 금액과 관계없이 중소기업자 간 경쟁
- 경쟁제품 해당 여부는 공고문에서 확인

#### 금액 환산

- 금액 기준은 추정가격(부가가치세 제외 금액)에 적용
- 공고의 기초금액이나 사업예산이 부가가치세 포함 금액이면 1.1로 나눠 추정가격으로 환산
- 부가가치세 포함 기준의 경계 금액은 1.1억원(1억원 기준)과 2.53억원(고시금액 2.3억원 기준)
- 고시금액은 「국가를 당사자로 하는 계약에 관한 법률」 제4조제1항에 따라 재정경제부장관이 2년마다 고시하는 물품과 용역의 금액
- 2025-2026년 적용 고시금액은 2.3억원
- 공고일이 2027년 이후이면 새 고시금액을 웹검색으로 확인

#### 학술연구 예외

- 같은 시행령 제2조의3은 정책 자문 용역(학술, 연구, 조사, 평가 등)의 우선조달계약 적용 예외를 허용
- 예외 적용 요건은 비영리법인의 입찰 참가 필요성
- 예외를 적용한 공고는 사유를 공고문에 기재
- 예외 공고에는 대형 컨설팅사도 입찰 가능
- 학술연구용역의 판정 근거는 공고문의 참가자격 문구와 예외 사유 기재 여부

#### SW사업 금액 기준

- 「소프트웨어 진흥법」 제48조와 과학기술정보통신부 고시 「중소 소프트웨어사업자의 사업 참여 지원에 관한 지침」 별표 1이 소프트웨어사업의 대기업 참여 하한을 정함
- 최신 고시 번호와 별표 1은 착수 시 확인 (고시 수시 개정)
- 이 기준의 대기업은 중소기업을 제외한 모든 소프트웨어사업자 (중견기업 포함)
- 대기업 참여 하한은 기업 구분별로 다름
    + (매출액 8천억원 이상 기업) 사업금액 80억원 이상 사업
    + (매출액 8천억원 미만 기업) 사업금액 40억원 이상 사업
    + (중소기업에서 중견기업이 된 지 5년 이내 기업) 사업금액 20억원 이상 사업
- 사업금액 20억원 미만 사업은 중소기업만 입찰 가능
- 상호출자제한기업집단 소속 회사는 예외사업에만 참여 가능
- SW사업의 사업금액은 추정가격에 부가가치세를 포함한 금액 (용역 금액 기준의 추정가격과 산정 방식이 다름)
- 발주기관은 대기업 참여제한 적용 여부를 공고문이나 RFP 에 명시할 의무를 가짐
- SW사업 판정은 공고문이나 RFP 의 대기업 참여제한 문구를 먼저 확인
- ISP 와 ISMP 같은 정보화 기획 용역은 SW사업 해당 여부를 공고문 문구로 확인
- (2024년 1월 정부 개선안) 중소기업 전용 사업 30억원 상향, 설계와 기획 사업 개방, 상호출자제한기업집단의 700억원 이상 사업 참여
- 개선안의 지침 반영 여부는 착수 시 현행 지침 별표 1로 확인
- 개선안 반영 여부와 공고문 문구가 다르면 공고문 문구를 우선 적용

#### 판정 적용

- 판정 결과가 중소기업자 이하로 제한되면 대형 컨설팅사 유형을 경쟁 구도에서 삭제
- 대형 컨설팅사 기본 후보 규칙은 대형 컨설팅사 유형이 남은 공고에만 적용
- 대학 산학협력단 유형은 기업 규모 판정과 관계없이 유지
- 자사 유사 기관과 업종 탐색 경로의 질의에는 기업 규모 조건과 지역 조건을 포함
    + (포함 이유) 조건을 충족하는 기관군을 처음부터 탐색
    + (예시 질의) "[지역] 소재 [업종] 소기업", "[과업 유형] 연구용역 중소기업 제한 낙찰"
- 판정 결과와 근거(공고문 문구, 또는 추정가격과 적용 조문)는 경쟁자 표 양식의 참가자격 판정 항목에 기재

#### 필터링 해제

- 사용자가 참가자격 필터링 없는 경쟁사 탐색을 요청하면 참가자격 판정과 판정 적용을 생략
- 필터링 해제 요청은 사용자 판단을 우선하는 장치 (제도의 개정 시점과 적용 방식이 자주 바뀜)
- 필터링 해제 시 대형 컨설팅사 기본 후보 규칙은 공고 금액과 관계없이 적용
- 필터링 해제 시 업종 탐색 경로의 참가자격 제외와 제외 기관 메모는 생략
- 필터링 해제 시 참가자격 판정 항목에는 "필터링 해제(사용자 요청)" 로 기재

### 탐색 경로

#### 낙찰 기록

- 나라장터의 개찰결과와 낙찰 결과를 웹검색으로 확인
- 나라장터 원 사이트는 자동 수집이 제한되는 경우가 많음
- 원 사이트 조회가 막히면 검색 결과에 노출된 재게시 페이지를 사용
- 사용 가능한 재게시 페이지
    + 민간 입찰정보 사이트의 공고 상세 페이지
    + 발주기관 홈페이지의 입찰공고 게시판
    + 발주기관 홈페이지의 우선협상대상자 선정 결과 게시판
    + 발주기관 홈페이지의 계약정보 공개 게시판
- 검색 엔진의 색인 대상은 주로 공고명
- 낙찰 기록은 2단계로 확인
    + (1단계) 동일 발주기관의 과거 동명 사업과 타 발주기관의 동일 유형 사업의 공고 페이지를 공고명으로 탐색
    + (2단계) 공고 페이지의 개찰결과, 낙찰자, 우선협상대상자 항목을 확인
    + (재검색) 공고 페이지에 해당 항목이 없으면 공고번호로 재검색
- 예시 질의는 "[과거 사업명] 개찰결과", "[과거 사업명] 우선협상대상자", "[공고번호] 낙찰자", "[발주기관명] 계약정보 공개 [과업 키워드]"
- 사용자가 제공한 나라장터 낙찰 결과도 낙찰 기록 경로로 기재

#### 수행 공개

- 수행사가 보도자료, 홈페이지 실적 목록, 블로그, SNS 로 알린 수주 사실을 검색
- 검색 범위는 동일 발주기관 사업과 타 발주기관의 동일 유형 사업
- 예시 질의는 "[발주기관명] 연구용역 수주", "[발주기관명] 착수보고회 수행기관", "[과업 유형] 수립 연구용역 최종보고회 수행기관"

#### 자사 유사 기관

- 자사 유사 기관 경로는 같은 발주기관 시장에서 제안사와 반복하여 경쟁하는 기관을 탐색
- 작업 폴더 company.md 의 사업 분야, 인력 규모, 수행실적 분야로 제안사 프로필을 정리
- 정리한 프로필과 같은 프로필의 기관을 검색
- 예시 질의는 "[자사 사업 분야] 전문 컨설팅 기업", "[자사 대표 과업 유형] 연구용역 수행기관"
- company.md 가 비어 있으면 착수 질의 11번 답변을 사용
- 두 자료가 모두 없으면 자사 유사 기관 경로를 생략

#### 업종 탐색

- 과업 특성에서 이 과업을 수행할 수 있는 업종을 도출
- 도출한 업종의 기업과 기관을 검색
- 업종 도출 예시
    + (ISP) IT 컨설팅사, SI 계열사
    + (R&D 성과분석) 과학기술 컨설팅사, 전문 연구기관
    + (지역 발전계획) 지역 연구원, 도시계획 엔지니어링사
- 검색 자료는 협회 회원사 목록, 업계 기사의 주요 기업 언급, 조합 질의
- 조합 질의는 RFP 의 과업 분야, 과업 유형, 발주기관 유형을 조합 (예: "OO 기본계획 수립 연구용역", "OO 분야 산학협력단 정책연구")
- RFP 참가자격(업종 등록, 대기업 참여 제한, 지역 제한)으로 입찰할 수 없는 기관은 제외

#### 대형 컨설팅사 기본 후보

- 적용 대상은 참가자격 판정에서 중견기업과 대기업의 입찰이 가능한 공고
- 필터링 해제 요청이 있으면 모든 공고에 적용
- 홈페이지에 공공 분야를 표방하지 않은 대형 컨설팅사도 공공 용역을 다수 수주
- 후보 선별 기준에서 공공 분야 표방 여부는 제외
- 기본 후보 기관군은 대형 회계법인 계열 컨설팅사, 대형 경영컨설팅사, 대형 교육협회형 기관
- (대형 교육협회형 기관) 경영교육과 인증 사업을 전면에 내세우는 협회 형태의 기관
- 대형 교육협회형 기관은 컨설팅사로 표방하지 않아도 공공 컨설팅 용역을 다수 수주
- 대형 교육협회형 기관은 컨설팅사 검색과 별도로 검색
- 기관명은 업계 기사와 공공 용역 수행 보도에서 검색으로 확보
- 과업 분야 수행 근거를 검색하여 선정 근거 열에 기재
- 근거가 확인되지 않으면 선정 근거 열에 "공공 용역 다수 수주 기관군" 으로 기재
- 출처는 기관 홈페이지 URL 과 확인일

#### 제외 기관

- 참가자격으로 제외한 기관은 제외 기관 메모에 기관명, 제외 사유, 확인 경로를 기재
- 전임 수행사나 확인 기관이 이번 공고에 입찰할 수 없으면 경쟁 강도가 달라짐
- 제외 사실은 유형별 강약점 서술에 반영

### 경로 수행 순서

- 낙찰 기록과 수행 공개 경로를 먼저 수행
- 두 경로의 확인 기관은 추정 후보보다 근거력이 높음
- 낙찰 기록과 수행 공개 경로는 결과 유무와 관계없이 수행
- 한 경로에서 연속 3회 질의가 기관을 찾지 못하면 다음 경로로 이동
- 남은 검색은 기관이 비어 있는 경쟁사 유형을 채우는 데 사용
- 자사 유사 기관과 업종 탐색 경로는 경쟁사 유형마다 기관이 1곳 이상 채워질 때까지 수행
- 과업에 해당하지 않는 경쟁사 유형은 제외
- 업종 탐색으로 도출한 새 경쟁사 유형은 추가

### 출처 기재

- 경쟁 후보 기관 표의 확인 경로 열에는 탐색 경로명 중 하나를 기재
- (확인 기관) 낙찰 기록과 수행 공개 경로로 찾은 기관
- (추정 후보) 자사 유사 기관과 업종 탐색 경로로 찾은 기관
- 강약점 서술은 확인 기관과 추정 후보를 구분하여 표기
- 유형별 예상 강약점은 경쟁 후보 기관 표를 근거로 추정
- 기관마다 출처 URL 을 기재
- 게시일이 확인되면 게시일을 기재
- 게시일이 확인되지 않으면 검색 일자를 "확인일" 로 기재
- 표에 기재하는 검색 기관은 출처 URL 이 있는 기관
- 사용자 제공 자료의 출처는 "사용자 제공(나라장터)" 로 기재

- 예시 행의 기준은 비정량 배점 합계 80점, 본문 슬라이드 40장

### 귀속 기준

- 비정량 세부항목 전건을 1개 이상 슬라이드의 `evalItems` 에 귀속 (귀속 0건은 lint FAIL)
- (배점 비중) 비정량 세부항목 배점 합계에서 해당 항목 배점이 차지하는 비율
- (슬라이드 비중) 본문 슬라이드 수에서 귀속 슬라이드 수가 차지하는 비율
- 본문 슬라이드는 표지, 목차, 간지, 종료를 제외한 슬라이드
- 슬라이드 비중이 배점 비중의 절반 이하이거나 두 배 이상이면 lint WARN
- 인력 배점(연구책임자, 참여인력)은 프로필 슬라이드에 귀속
- 관리 배점(일정, 품질, 보안)은 사업관리부문 슬라이드에 귀속
- 실적 배점이 정량이면 실적 슬라이드를 1장으로 제한
- 실적 배점이 정성이면 실적 카드 슬라이드를 추가
- 평가항목 병기형 헤더(배점 표의 항목 순서를 목차로 채택하는 RFP)는 section 에 평가항목 번호를 표기
- 슬라이드 본문의 평가 내부 어휘(배점, 채점, 방어 논리, 결정 장소, 귀속)는 lint FAIL
- 대응 관계는 섹션대장과 붙임 참조표에만 표시
