## Decisions

- (Decision) The decision the report recipient will make after reading the planning report. If there is no report recipient, what the document settles. For an information document, what the reader becomes able to do with it [확인]
- (Persuasion grounds) The grounds the report recipient requires for that decision. For example budget grounds, comparison alternatives, implementation schedule, investment payback outlook, and so on [확인]

## Problem Statement

- (Situation) The current state of the document's actor and topic. Enter only confirmed facts [확인]
- (Problem) The gap between the state the actor aims to reach and the situation. Give the supporting material for the target state alongside [확인]
- (Key question) One question the whole document answers [확인]
- (Scope and constraints) The areas the solution covers, excluded areas, and constraints (budget, laws, schedule, and so on) [확인]
- (Stream) One of goal-setting, gap analysis, and combination, with one line of grounds for the verdict [확인]
