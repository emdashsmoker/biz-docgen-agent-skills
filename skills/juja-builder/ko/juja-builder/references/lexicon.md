# 제안서 어휘 사전

- `check tone`이 비관행 어휘를 FAIL로 색출하면 대체표의 어휘로 교체
- 금칙어 목록만 있으면 모델은 금칙어의 우회 표현으로 구어나 비유 어휘를 만듦. 기능별 관행 어휘 표는 그 자리의 어휘를 제시

## 기능별 관행 어휘

| 기능 | 관행 어휘 (제안서 빈출) | 용례 |
|------|------------------------------|------|
| 조사 | 조사, 수집, 검토, 파악, 분석, 대조, 실사, 면담, 설문 | 국내외 사례를 조사하여 비교표를 작성 |
| 도출 | 도출, 선정, 설계, 수립, 작성, 정의, 분류, 산정 | 우선순위 평가 기준을 설계하여 과제 후보를 선정 |
| 검증 | 검증, 확인, 검토, 자문, 협의, 확정, 보완 | 자문위원회 검토를 거쳐 지표 체계를 확정 |
| 연계 | 연계, 반영, 활용, 적용, 전달, 종합 | 조사 결과를 전략 도출의 근거 자료로 활용 |
| 산출 | 산출물, 결과물, 보고서, 목록, 체계, 방안, 계획 | 최종 산출물은 기본계획서와 이행과제 정의서 |

| 과정 | 단계, 절차, 순서, 회차, 시기, 기간 | 착수 후 3주 내에 조사 설계를 확정 |

## 대체표

- 왼쪽 어휘는 `check tone`이 색출. 오른쪽 어휘로 교체
- 밀도와 체크는 코드 색출 대상 밖. 입력과 출력은 "입력이", "입력으로", "입력되", "입력 자료", "입력값", "출력이", "출력으로", "출력물", "출력값" 같은 결합 형태만 코드가 색출. 그 밖의 형태는 작성 시 직접 확인
- 색출 어휘의 원천은 scripts/proposal.py 설정부 TONE_FAIL. 이 표와 설정부가 어긋나면 설정부가 기준

## 라벨 어휘

- 괄호 소제목은 ❍와 하이픈 계위에만 사용. 붙이는 기준은 SKILL.md 괄호 소제목 절
- 괄호 소제목의 낱말은 나열 묶음을 가르는 기준의 이름에서 가져옴. 예시로 등급 구분은 (공개 등급) (내부 등급), 단계 구분은 (기획 단계) (평가 단계), 대상 구분은 (국내 사례) (해외 사례)
- Task 서술의 라벨은 references/methods.md 공통 표준 절을 적용

## 종결 어휘

- 명사형 종결은 자연스러운 한국어 문장이 되는 형태만 사용
- 권장 종결은 -수행, -도출, -확보, -제시, -수립, -작성, -반영, -확정, -분석, -조사, -필요, -예정, -상태, -전망
- 부자연 종결 예시는 "-구조로 우선", "-결론", "-훌륭", "-체계임을"
- 판정 문장의 종결은 "-으로 확인", "-으로 집계", "-으로 나타남", "-인 상황", "-인 실정"
- 구어체 "것" 종결은 쓰지 않음. "남은 것" → "OO 잔존", "해야 할 것" → "OO 필요", "과업의 포인트인 것" → "OO이 과업의 핵심", "OO하는 것" → "OO 수행", "OO것임" → 명사형 종결
- `check tone`의 "것" 판정 대상은 줄 끝의 "것" 종결

## 결과 표현 전환표

- 왼쪽은 작성자의 판단 과정을 드러내는 표현. 오른쪽처럼 발주처가 받는 산출물, 시점, 효과로 바꿔 씀

| 사고 과정 표현 | 결과 표현 |
|----------------|-----------|
| 역산하여 일정을 편성 | 중간보고 시점까지 조사 결과표를 제출 |
| 검토하여 판단 | 기준표에 제시한 기준으로 선정 |
| 고려하여 배치 | 세부 과업별 산출물과 제출 시점을 조견표로 제시 |
| 이를 바탕으로 도출 | 조사 결과 표의 항목을 후보로 제시 |
| 필요성을 인식하여 | (삭제 후 필요성의 근거 사실을 서술) |
| 우선순위를 판단하여 | 평가 기준표의 배점과 산식으로 우선순위를 산정 |
| 적절히, 합리적으로, 효과적으로 | (삭제 후 수치나 기준으로 대체) |
| 3대 전략, 4가지 방안 | (개수 삭제) 전략 항목을 □로 직접 제시 |
| RFP 요구사항에 부합하는, 제안요청서의 취지에 맞는 | (삭제) 요구항목 원문 표기를 Task 명칭과 서술에 사용 |
| 본 과업은, 본 제안은, 본 연구에서는 | (삭제) 내용으로 시작. 지칭이 필요하면 사업명 실명 |
| RFP가 제시한, RFP가 요구한 | (삭제 후 내용 직접 서술) |
| 발주처는 OO을 확보, 발주처가 OO을 달성 | (주어 삭제) 서술부에 대상과 상태를 기입 |
| N년까지 OO 확정, 최종보고 즉시 적용 (추진전략 문장) | (완료 시점은 추진일정표로 이동) 수행 방식과 그 방식이 만드는 변화를 서술 |
| 발주처 협의, 발주처 담당자, 발주처 제공 자료 | 기관 호칭 절(제안서는 00_제안전략서.md, 사전진단보고서는 00_진단서.md)의 기관명으로 기입 |
| 아래 표는, 다음 표는 OO 예시 | (삭제) 표 앞에 표의 요지를 담은 ❍를 배치. 예시 여부는 표 아래 ※ |
| 첫째, 둘째, 셋째, 첫 번째, 하나는 OO 다른 하나는, 마지막으로 | (삭제) 항목마다 ❍ 1개. 4개 이상이면 표 |
